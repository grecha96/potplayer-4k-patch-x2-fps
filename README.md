# PotPlayer 4K Patch — удвоение кадров на 4K

Патч для мода удвоения кадров (2x FPS) в PotPlayer. Снимает жёсткое ограничение
разрешения и добавляет отдельный профиль параметров для 4K.

## Проблема

В профилях `Fastest.avs`, `Fast.avs`, `Medium.avs`, `High.avs`, `Highest.avs`
в конце стоит ограничитель:

```
zub = width * height
...
Framerate > 30.5 ? ... : zub < 2305000 ? eval("interpolate()") : eval("")
```

`2305000` — это 1920×1200. Для 4K (8.29 млн пикселей) условие всегда ложно,
поэтому интерполяция **молча не запускается**: мод работает на FullHD и
не работает на 4K. Плюс сами параметры рассчитаны максимум на FullHD.

## Что делает патч

1. Меняет порог `2305000` на `99999999` — ограничение снимается.
2. Добавляет ветку для разрешений выше 2304000 пикселей с параметрами под 4K:
   блок 32×32, `pel:1`, GPU-алгоритм `algo:13`, тщательность растёт от Fastest
   к Highest.
3. Для профиля **Fastest** включает `cubic:0,linear:false` — убирает слабый
   «звон» по контурам при движении.
4. Делает резервные копии исходных скриптов в `backup\`.
5. Проверяет версию PotPlayer и предупреждает, если сборка отличается от
   тестируемой.

## Требования

- **PotPlayer 64-bit**, тестировалось на **1.7.23159**.
- Установленный мод удвоения кадров: файлы `*.avs` в папке PotPlayer и
  `svpflow1.dll` / `svpflow2.dll` рядом с `PotPlayerMini64.exe`.
- Права администратора (файлы лежат в `Program Files`).

> **Патч не содержит и не устанавливает `svpflow*.dll`** — это сторонние
> библиотеки SVP Team. Если их нет, установите SVP (svp-team.com), чтобы они
> появились в папке PotPlayer, и запустите патч снова.

## Установка

1. Скачайте репозиторий: **Code → Download ZIP** (или `git clone`).
2. Распакуйте в любую папку.
3. Запустите `patch.cmd` — он сам запросит права администратора.
4. Перезапустите PotPlayer, откройте 4K-видео, проверьте загрузку GPU
   (`nvidia-smi` или OSD плеера по Tab).

## Откат

```
patch.cmd -Revert
```

Восстанавливает файлы из `backup\`. Бэкап создаётся при первом запуске,
откатиться можно в любой момент.

## Ограничения

- Мод срабатывает только на видео с частотой **≤ 30.5 fps** — 60 fps удваивать
  не нужно, это условие оставлено как есть.
- 4K + 2x — тяжёлая нагрузка. Начинайте с профиля **Fast** или **Medium**;
  Highest на 4K может не вытянуть в реальном времени.
- Нужна аппаратная обработка AviSynth в PotPlayer (`gpu>=1`), иначе скрипт
  уйдёт в CPU-ветку и на 4K будет тормозить.
- Патч правит только файлы, которые уже есть в установке. Незнакомый файл он
  пропускает и пишет об этом в `patch.log`.

## Частые вопросы

**Ничего не изменилось после запуска.**
Проверьте `patch.log` в папке патча. Если там `no .avs profile scripts found`,
значит мод не установлен или лежит в другой папке.

**Пишет, что не хватает svpflow*.dll.**
Установите SVP — патч намеренно не распространяет эти библиотеки.

**Артефакты при движении.**
Переключитесь на профиль Fastest: меньше обработки — меньше поводов испортить
кадр. Именно он даёт самую чистую картинку на 4K.
